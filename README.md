# 经营管理驾驶舱

漫剧招生 · 漫剧制作 · 企业AI服务 · 企业销售 经营看板（静态网站，Vercel 部署）。

- `index.html`：页面结构与样式
- `runtime.js`：运行层（读取数据、计算、调度绘制）
- `lib.js` / `calcs.js` / `draws.js`：图表组件、指标计算、各图表绘制
- `data.js`：**示例数据**（非真实经营数据），替换此文件即可换成真实数据

图表库 d3 v7.9.0 随仓库一起提供（d3.min.js），不依赖外部 CDN。

## 工作流演示层（workflow.js）

按《客户A CEO 驾驶舱 PRD v0.2》补的演示功能，数据存在浏览器本地，右上角「重置演示」恢复初始状态。

- 右上角「当前账号」切换 10 个岗位（CEO、财务、销售主管、销售、制作负责人、质检、培训负责人、班务、AI服务负责人、权限管理员），页签、数据范围、可执行动作随岗位变化，无权限的卡片打码（R13）
- 「我的工作台」：本人待办 + 按岗位出现的模块：应收分期与核销（R01/R11）、风险处置（R03）、商机跟进与丢单（R10/R11）、组内对比与人效更正复核（R12）、质检与交付批次（R06/R07）、接单评估（R02）、转班与退费（R05）、AI 里程碑转应收（R08）、权限矩阵与协作授权、操作留痕（R13）
- 首条评审用例：CEO 点总看板的「应收款逾期」预警 → 看合同/分期/余额/责任人 → 切「销售」登记付款答复 → 切「财务」认领流水核销 → 切回 CEO，现金流卡的应收余额已减少，在待办里复核关闭风险
